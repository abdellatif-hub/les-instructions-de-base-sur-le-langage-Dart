# Exercice 1 : Fonctions avec paramètres facultatifs nommés
Énoncé :
Écris une fonction afficherInfos qui prend comme paramètre obligatoire le nom d’une personne, et comme paramètres facultatifs nommés : age et ville. Si l’âge ou la ville ne sont pas fournis, la fonction doit afficher 'non spécifié'. Ensuite, appelle la fonction avec plusieurs combinaisons.
